# 🏠 Plataforma para Corretor de Imóveis

Plataforma web full-stack desenvolvida para a exibição, busca e gestão de catálogo imobiliário. O projeto foca em oferecer uma experiência moderna e fluida para clientes interessados em comprar ou alugar imóveis, além de facilitar o contato direto com o corretor.

🔗 **Acesse o projeto online:** [corretor-imoveis-frontend.onrender.com](https://corretor-imoveis-frontend.onrender.com/)

---

### 🚀 Funcionalidades
* **Catálogo de Imóveis:** Listagem interativa com fotos, descrições detalhadas, preços e status do imóvel.
* **Filtros de Busca:** Navegação facilitada para encontrar propriedades por categoria e localização.
* **Contato Direto:** Integração para envio de mensagens e agendamento de visitas diretamente com o corretor.
* **Design Responsivo:** Interface otimizada para smartphones, tablets e computadores.

---

### 🛠️ Tecnologias Utilizadas
* **Frontend:** JavaScript, HTML5, CSS3
* **Backend:** Python
* **Hospedagem:** Render (Full-stack)
